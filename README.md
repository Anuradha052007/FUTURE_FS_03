# Brew & Bite Café Website

## Project Overview

I created a professional restaurant website called “Brew & Bite Café” using HTML, CSS, and JavaScript. The website includes a modern homepage, animated menu cards, gallery section, customer reviews, online table booking form, and contact information.

## How This Website Helps the Business

This website helps the business grow by improving online visibility, attracting more customers, and making table booking easier. Customers can explore menu items, view reviews, and contact the café easily.

## Features

* Responsive Design
* Animated Hero Section
* Food Menu Cards
* Gallery Section
* Customer Reviews
* Table Booking Form
* Contact Information
* Smooth Animations

## Technologies Used

* HTML
* CSS
* JavaScript
* GitHub Pages
